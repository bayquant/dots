# File Naming

These rules apply to documents (papers, books, notes, slides). Code files follow their language's conventions instead (e.g. Python modules stay `snake_case`).

- **kebab-case everywhere**: all lowercase, words separated by hyphens, no spaces or underscores.
- **Books**: `title-lastname.pdf` (e.g. `options-futures-and-other-derivatives-hull.pdf`).
- **Papers**: `title-lastname-year.pdf` when the year is known (e.g. `the-pricing-of-options-and-corporate-liabilities-black-scholes-1973.pdf`), otherwise `title-lastname.pdf`.
- **Authors**: 1 author: surname. 2 authors: both surnames. 3+ authors: first author + `et-al`.
- **Numbers are zero-padded to 2 digits** wherever they indicate order (`lecture-01`, `problem-set-01`) so they sort correctly past 9. The number goes right after the category name; any extra descriptor comes after it (`lecture-01-annotated.pdf`).
- **Fix typos** in source filenames when renaming; don't preserve them.
