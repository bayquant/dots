# Math Style

## Variables and Arguments

Write a symbol's argument only when its dependence is the point.

1. Define a quantity with its argument the first time: `x(t)`.
2. Keep the argument when the function itself is the object (definitions, integrals, "f(t) is known").
3. Drop it in pointwise equations where every term is at the same instant, and say so once.
4. Keep it when evaluating at a specific point: `x(t_0)`, `x(T)`.
5. Constants never take an argument.
6. Never mix styles inside one equation.
